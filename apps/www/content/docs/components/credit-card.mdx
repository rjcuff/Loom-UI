## Usage

```tsx
import { CreditCard } from "@/components/ui/credit-card"
```

```tsx
<CreditCard holder="Ada Lovelace" expiry="09/30" />
```

Nothing on the card is real and no network mark is drawn, so it is safe to put
in a mockup, a pricing page or a checkout screenshot. The default number is the
one every payment provider reserves for test cards.

### The aurora

Four blobs sit inside the face and drift across it, each on its own cycle so the
wash never lands back where it started. Over them goes one layer of glass, a
fixed gloss that gives the face its plastic edge. Nothing reacts to the pointer:
the card is a mockup, not a target.

```tsx
<CreditCard colors={["#f472b6", "#fb923c", "#facc15"]} duration={24} />
```

One blob is drawn per colour. A longer `duration` gives a slower, calmer wash.
`disabled` stops the drift and leaves the face still.

### Masking

```tsx
<CreditCard masked />
```

Every digit but the last four becomes a bullet, with the grouping left alone, so
`4242 4242 4242 4242` reads as `•••• •••• •••• 4242`.

### Turning it over

The card draws one face at a time rather than owning a flip, so pair it with
[Flip Card](/docs/components/flip-card) and both sides come from the same props:

```tsx
<FlipCard
  className="w-full max-w-md"
  front={<CreditCard />}
  back={<CreditCard side="back" />}
/>
```

The back has the magnetic stripe, the signature panel and the security code.

## Props

| Prop        | Type                | Default            | Description                             |
| ----------- | ------------------- | ------------------ | --------------------------------------- |
| `side`      | `"front" \| "back"` | `"front"`          | Which face to draw.                     |
| `number`    | `string`            | `"4242 4242 …"`    | Number across the face.                 |
| `holder`    | `string`            | `"A. Placeholder"` | Name along the bottom.                  |
| `expiry`    | `string`            | `"04/29"`          | Expiry along the bottom.                |
| `cvv`       | `string`            | `"123"`            | Security code on the back.              |
| `issuer`    | `ReactNode`         | `"Loom"`           | Name in the top left.                   |
| `brand`     | `ReactNode`         | placeholder rings  | Mark in the bottom right.               |
| `masked`    | `boolean`           | `false`            | Show only the last four digits.         |
| `colors`    | `string[]`          | teal to violet     | Aurora palette. One blob per colour.    |
| `duration`  | `number`            | `16`               | Seconds for one drift of a single blob. |
| `disabled`  | `boolean`           | `false`            | Render the face still.                  |
| `className` | `string`            | none               | Merged onto the card. Width goes here.  |

Any other `<div>` prop is forwarded.

<Callout title="Aspect ratio">
  The card is `aspect-[1.586]`, which is the real ID-1 ratio, and it fills the
  width it is given up to `26rem`. Set the width on `className` and the height
  follows.
</Callout>

<Callout type="tip" title="Accessibility">
  The plate, the arcs and the brand rings are decoration and are hidden from
  assistive tech. The number, name and expiry are plain text, so they are read
  in the order they are printed. With reduced motion the aurora holds still.
</Callout>
